# راه‌اندازی OpenAI در Catalog Intelligence v8.1

- API Key را برای شخص دیگری نفرستید.
- ترجیحا یک Project Key مخصوص 3DPrintHub بسازید.
- در برنامه، کلید با Windows Credential Store ذخیره می‌شود.
- اگر `OPENAI_API_KEY` در Environment وجود داشته باشد، همان اولویت دارد.
- مدل ثابت نداریم؛ برنامه ابتدا مدل‌های قابل‌دسترسی همان Project/Key را می‌خواند و از بین آن‌ها مدل مناسب را انتخاب می‌کند.
- می‌توانید در تنظیمات مدل را تغییر دهید.
- دکمه «تست اتصال OpenAI» فقط اعتبار اتصال/کلید را بررسی می‌کند.
- تولید پکیج محتوا از Responses API و Structured Output استفاده می‌کند.

اگر مدلی در Project شما مجاز نباشد، برنامه بعد از دریافت فهرست مدل‌ها روی مدل قابل‌دسترسی دیگری می‌رود و مدل نامعتبر را تحمیل نمی‌کند.
