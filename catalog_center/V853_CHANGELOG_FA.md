# 3DPrintHub Catalog Intelligence v8.5.3

- رفع علت واقعی اجرای `v8.5.1`: حذف اجرای محیطی `python -m app.main` که از پوشه جاری PowerShell قابل سایه‌اندازی بود.
- افزودن `launch.py` با مسیر مطلق و کنترل هم‌زمان Version، Build و Source Root پیش از بازکردن UI.
- افزودن تست رگرسیون واقعی که لانچر را از داخل یک پوشه جعلی حاوی `app v8.5.1` اجرا می‌کند و الزام می‌کند `v8.5.3` بارگذاری شود.
- اصلاح `RUN.ps1` و `RUN_DEBUG.ps1` برای استقلال کامل از مسیر فعلی PowerShell.
- افزودن `INSTALL_AND_RUN.ps1` برای نصب، اعتبارسنجی نسخه نصب‌شده و اجرای مستقیم همان نسخه.
- ساخت ZIP با فایل‌ها در ریشه آرشیو؛ Extract مستقیم دیگر یک پوشه مادر مخفی داخل مسیر نصب ایجاد نمی‌کند.
- سربرگ رسمی سرمه‌ای/طلایی با لوگوی افقی، شماره نسخه، Build ID و مسیر فایل فعال.
- حفظ کامل SQLite، Windows Credential Store، FTP/HTTPS Bridge و تمام تنظیمات قبلی بدون Migration جدید.
