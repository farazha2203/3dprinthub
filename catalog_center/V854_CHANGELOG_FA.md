# 3DPrintHub Catalog Intelligence v8.5.4

- رفع مشکل Paste در فیلد `Bridge Token` با نگه‌داشتن مرجع مستقل `self.bridge_token_entry`.
- پشتیبانی از `Ctrl+V`، `Shift+Insert`، راست‌کلیک و دکمه واضح «چسباندن توکن».
- افزودن دکمه «نمایش/مخفی» برای کنترل دیداری مقدار واردشده پیش از ذخیره.
- پذیرش هر دو قالب «خود توکن» و خط کامل `CATALOG_BRIDGE_TOKEN=...` و حذف فاصله، CR/LF و کوتیشن بیرونی.
- استفاده از یک مسیر Normalization مشترک برای Paste، تست اتصال و ذخیره تا نام متغیر محیطی هرگز به‌عنوان بخشی از توکن ذخیره نشود.
- حفظ Bridge Token فقط در Windows Credential Store؛ بدون ذخیره مقدار حساس در SQLite یا Log.
- افزودن تست‌های رگرسیون برای ورودی ساده، خط `.env`، کوتیشن، Clipboard چندخطی، میان‌برهای صفحه‌کلید، نمایش/مخفی و عدم ذخیره در SQLite.
- حفظ لانچر مطلق، نصب اتمیک، Backup/Rollback، Bridge سمت سایت، دیتابیس مستقل و دو فایل برند بدون تغییر بایتی.
