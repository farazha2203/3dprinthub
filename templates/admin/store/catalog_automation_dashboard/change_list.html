راهنمای سریع

۱. ابتدا «تست اتصال» TGJU را بزن. نتیجه باید نرخ فعلی و سقف روز را نشان دهد.

۲. «بروزرسانی نرخ دلار» را بزن تا Snapshot ساخته شود.

۳. Bambu را تست و سپس همگام کن. قیمت قبلی و جدید در «قیمت فعلی و قبلی Bambu» و تمام Snapshotها در «تاریخچه کامل قیمت Bambu» دیده می‌شوند.

۴. در متریال‌ها لینک رسمی محصول Bambu یا نام دقیق مشابه را تنظیم کن.

۵. «بروزرسانی کامل» قیمت فروش هر گرم را با بیشترین نرخ دلار روز محاسبه می‌کند.

وضعیت واقعی منابع و روش جایگزین

TGJU: دریافت مستقیم نرخ فعلی و سقف روز؛ بدون API.

Bambu Lab: ابتدا JSON مجموعه، سپس HTML مجموعه و در نهایت فایل استاندارد product.js هر محصول امتحان می‌شود.

Printables: دریافت خودکار فعال است.

Thingiverse: فقط API رسمی؛ نبود توکن «نیازمند تنظیمات» است، نه خرابی سیستم.

MakerWorld: فهرست عمومی، Sitemap و سپس لینک بذر ادمین بررسی می‌شود. HTTP 403 دور زده نمی‌شود.

GrabCAD: به‌علت JavaScript/403 و محدودیت استفاده، فقط لینک‌های بذر و مرجع داخلی ادمین؛ انتشار عمومی غیرفعال است.
