## Source-of-truth rule
When Buffer API behavior, field names, enums, scopes, scheduling modes, or Instagram metadata change, these official Buffer documents override copied examples in this repository.

Do not copy API keys, account secrets, or authenticated Buffer responses into this documentation tree.
