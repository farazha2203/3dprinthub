# 3DPrintHub Instagram Style Guide

Status: OWNER APPROVED — 2026-09-17
Style ID: `3dprinthub_instagram_gold_navy_v1`

## Visual system
- Deep navy / near-black backgrounds.
- Metallic gold borders, icons and 3D accents.
- Warm cinematic product lighting; premium, clean and uncluttered.
- Persian-first typography with short English support text only where useful.
- Product remains the visual hero; no generic stock-photo look.
- Highlight covers use one centered 3D object inside a gold circular ring.
- Story templates use a top brand mark, one short headline, product image, CTA and `3dprinthub.ir`.

## Approved highlight categories
`آباژور` · `پایه کیک` · `اکسسوری کریسمس` · `اکسسوری تولد`
`اسباب بازی` · `فلکسیبل` · `قطعات سفارشی` · `قطعات خودرو`

## Asset sizes
- Profile logo: 1080×1080 PNG/WebP.
- Highlight cover: 1080×1080 PNG/WebP; keep icon inside safe central circle.
- Story: 1080×1920; keep critical text away from top/bottom UI zones.
- Feed: prefer 1080×1350 portrait for product posts when the source supports it.
