# فاز ۳۳: Deadline اتوماسیون، توقف اجرا و فونت پنل

## هدف

این فاز دو مشکل عملیاتی پنل مدیریت را برطرف می‌کند:

1. رکوردهای دریافت و همگام‌سازی که پس از قطع Worker یا Timeout برای همیشه در وضعیت «در حال اجرا» می‌مانند.
2. اعمال‌نشدن یکنواخت فونت IRANSans در داشبورد، منوی کناری، جدول‌ها و فرم‌های مدیریت.

## رفتار جدید Deadline

- هر `ExternalSourceFetchLog` هنگام شروع، `deadline_at` و `heartbeat_at` می‌گیرد.
- هر `CatalogSyncRun` هنگام شروع، Deadline ثابت و Heartbeat می‌گیرد.
- عملیات طولانی در نقاط امن، وضعیت توقف یا پایان مهلت را دوباره از دیتابیس می‌خواند.
- Watchdog رکوردهای قدیمی بدون Deadline را با استفاده از زمان آخرین فعالیت شناسایی می‌کند.
- توقف دستی وضعیت را `cancelled` می‌کند.
- پایان مهلت وضعیت را `failed` با مرحله `deadline_exceeded` می‌کند.

مقادیر پیش‌فرض:

| عملیات | مهلت |
|---|---:|
| TGJU تست یا دریافت نرخ | ۵ دقیقه |
| Bambu تست | ۱۰ دقیقه |
| Bambu همگام‌سازی | ۴۵ دقیقه |
| تست منابع مدل | ۱۰ تا ۱۵ دقیقه |
| MakerWorld / Printables Sync | ۹۰ دقیقه |
| Thingiverse Sync | ۴۵ دقیقه |
| GrabCAD Sync | ۳۰ دقیقه |
| صف کاتالوگ قبل از شروع | ۴۵ دقیقه |

این مقادیر با متغیرهای محیطی قابل تغییرند، اما برای اجرا ضروری نیستند.

## کنترل‌های جدید پنل

در داشبورد اتوماسیون اضافه می‌شود:

- تعداد اجراهای فعال و منقضی
- ستون «مهلت»
- دکمه توقف هر ردیف فعال
- دکمه توقف همه اجراهای گیرکرده
- Action توقف در فهرست Admin

کنترل توقف فقط برای Superuser فعال است.

## محدودیت فنی توقف

توقف دستی نمی‌تواند یک Socket مسدودشده را در سطح سیستم‌عامل فوراً Kill کند. رکورد در دیتابیس متوقف می‌شود و Worker در نزدیک‌ترین Checkpoint پایان می‌یابد. Timeout شبکه هر Adapter همچنان لایه اول محافظت است.

## اجرای دوره‌ای

فرمان اصلی فاز ۱۰ اکنون Watchdog را قبل از پردازش صف اجرا می‌کند. اگر Cron فاز ۱۰ هر چند دقیقه اجرا شود، Cron جدا لازم نیست.

برای کنترل مستقل می‌توان Cron زیر را هر پنج دقیقه ثبت کرد:

```text
*/5 * * * * /home/sfkilvrs/3dprinthub/deploy/cpanel/run_phase33_watchdog_cron.sh >> /home/sfkilvrs/3dprinthub/logs/automation_watchdog.log 2>&1
```

## فونت

CSS پنل Django/Velzon و SmartBase فونت IRANSans را روی Navigation، Sidebar، Table، Form، Modal و Dropdown اجبار می‌کند. Font family آیکون‌های RemixIcon، Boxicons و Material Design Icons جداگانه بازیابی شده تا آیکون‌ها خراب نشوند.

فایل فونت وارد Git یا بسته انتشار نمی‌شود و از فایل دارای مجوز موجود روی کامپیوتر و سرور استفاده می‌شود.
