# گزارش فاز ۱۹ — پنل Velzon، چت، مدارک خصوصی و ورود گوگل

## علت خرابی پنل ادمین

- فایل اصلی `app.js` قالب Velzon به عنصر `#two-column-menu` وابسته بود، اما این عنصر در Sidebar نسخه نیمه‌پیاده‌شده وجود نداشت؛ اجرای JavaScript در میانه متوقف می‌شد.
- دکمه منوی موبایل، تغییر تم و Fullscreen هم‌زمان توسط کد اصلی Velzon و فایل سفارشی کنترل می‌شدند و بعضی رویدادها دوبار اجرا می‌شدند.
- ترتیب لود فایل‌های RTL و Layout استاندارد Velzon رعایت نشده بود و در شروع صفحه، چیدمان برای لحظه‌ای به هم می‌ریخت.
- بخشی از کتابخانه‌های اصلی مانند SimpleBar، plugins.js و فایل‌های استاندارد Bootstrap/Feather به‌صورت کامل در مسیر مورد استفاده پنل قرار نداشتند.

## اصلاحات پنل ادمین

- جایگزینی هسته RTL با Assetهای اصلی نسخه خریداری‌شده Velzon.
- لود `layout.js` پیش از CSS برای جلوگیری از Flash چیدمان.
- بازگرداندن `#two-column-menu` و SimpleBar استاندارد.
- حذف کنترل‌های تکراری از `velzon-admin.js`.
- تثبیت ارتفاع و اسکرول Sidebar در دسکتاپ و موبایل.
- اضافه‌شدن منوی گفت‌وگوهای پشتیبانی و نشان پیام خوانده‌نشده.
- اضافه‌شدن دسترسی مستقیم به منابع خارجی، کاتالوگ و به‌روزرسانی قیمت‌های موجود پروژه.
- استفاده یکپارچه از IRANSans FaNum بدون خراب‌شدن فونت آیکون‌های Remix/Boxicons.

## چت پشتیبانی

- چت شناور روی فرانت برای مشتری واردشده.
- صفحه کامل گفت‌وگو داخل پنل مشتری.
- مرکز پاسخ‌گویی اختصاصی داخل Django Admin.
- ارتباط بر پایه دیتابیس و Polling؛ بدون نیاز اجباری به Redis یا WebSocket.
- بروزرسانی صفحه کامل و ادمین هر ۵ ثانیه و ویجت هر ۱۵ ثانیه.
- امکان پیوست تصویر، PDF، فایل Office، Archive و فایل‌های مهندسی سه‌بعدی.
- کنترل دسترسی بر اساس مالک گفت‌وگو و Permission کارمند.

## فرم سفارش و مدارک

- حفظ تصاویر الزامی از چهار زاویه و دو تصویر تکمیلی.
- امکان بارگذاری حداکثر ۵ مدرک فنی، هرکدام تا ۲۰ مگابایت.
- ذخیره مدارک و پیوست‌های چت خارج از Media عمومی.
- نمایش Thumbnail تصاویر و پیش‌نمایش امن PDF برای مشتری و مدیریت.
- دانلود امن STL، STEP، OBJ، 3MF و فایل‌های مشابه.
- نمایش خلاصه مشتری، مشخصات فنی، دما، محیط کار، تماس با مواد و گالری کامل در صفحه سفارش ادمین.

## ورود با گوگل

- اضافه‌شدن django-allauth و Provider گوگل.
- ورود با POST و PKCE.
- ساخته‌شدن خودکار CustomerProfile برای کاربران گوگل.
- شماره تماس پروفایل برای کاربر گوگل در شروع اختیاری است و بعداً از پنل تکمیل می‌شود.
- Client ID و Secret فقط از `.env` خوانده می‌شوند و در سورس ذخیره نشده‌اند.

## امنیت

- فایل‌های Backup قدیمی `config/settings.py.backup` و `config/settings.py.bak_revenue_20260720_165735` به‌علت داشتن Secret و اطلاعات دیتابیس از خروجی حذف شدند.
- فایل‌های خصوصی URL عمومی ندارند و فقط از Viewهای کنترل‌شده قابل دریافت‌اند.
- کارمند برای مشاهده مدارک سفارش باید Permission مشاهده سفارش و برای فایل چت باید Permission مشاهده گفت‌وگو را داشته باشد.
- Django از 6.0.6 به 6.0.7 ارتقا داده شد.
