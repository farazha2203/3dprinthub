# فاز ۲۷.۲ — اسلایدر قابل‌فهم و تثبیت تست‌ها

## اصلاح تصویر Hero

هر اسلاید دو لایه دارد:

1. تصویر محو و Cover برای پرکردن تمام پس‌زمینه.
2. تصویر اصلی با `object-fit: contain` برای نمایش کامل محصول بدون بریدن سوژه.

نسبت تصویر پس از Load به Landscape، Square یا Portrait طبقه‌بندی می‌شود. در موبایل تصویر در قاب مستقل بالای متن نمایش داده می‌شود و اندازه قاب با ارتفاع صفحه تغییر می‌کند.

## اصلاحات پایداری

- تعیین صریح Backend ورود پس از ثبت‌نام در پروژه دارای چند Authentication Backend.
- نمایش منابع قدیمی کاتالوگ که هنوز `CatalogSourcePolicy` ندارند؛ Policy موجود و غیرفعال همچنان جلوی نمایش را می‌گیرد.
- حفظ رفتار قطعی مرتب‌سازی جدیدترین محصولات و صفحه‌بندی ۱۸تایی.
- هماهنگ‌سازی تست‌های قدیمی فازهای ۱۳، ۱۴ و ۱۸ با کاتالوگ مرجع فاز ۲۳ و Hero فاز ۲۷.
- اصلاح انتظار تست Velzon برای Namespace واقعی `velzon_master`.

## Migration جاافتاده

Installer ابتدا `makemigrations store --check --dry-run` اجرا می‌کند. در صورت وجود اختلاف واقعی میان مدل‌ها و Migrationها، یک Migration با نام `phase27_2_state_sync` تولید، سپس اجرا و دوباره بررسی می‌شود. فایل تولیدشده باید همراه کد Commit شود.
