# Shared Integrations
Use provider adapters/services.

SMS/OTP: document config, templates/sender, expiry/single-use, retry/timeout, rate limits, delivery logs, outage/fallback and tests.
Telegram: document auth, webhook/polling, idempotency, retries, media, rate limits, logs, recovery and tests.
WhatsApp: use approved/official API/provider; document auth, webhook verification, templates, retries, idempotency, rate limits, media, logs and recovery.
