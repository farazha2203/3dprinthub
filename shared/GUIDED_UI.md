# Guided UI Standard
Every important option/action must explain: 1) what it does, 2) why it exists, 3) where result is used, 4) prerequisites, 5) required data, 6) how to configure, 7) what happens next, 8) dependencies, 9) verification, 10) common errors.

Dependent workflows must be numbered. Block/safely disable later mandatory steps when prerequisites are missing, explain why, and provide a direct action to complete them. Dashboards must show real counts, setup progress, pending work, integration/health status and missing setup; no hard-coded operational counts.
